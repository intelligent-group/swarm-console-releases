# Installing Swarm Console

## Windows

1. [Download the installer](https://swarm.intelligentit.io/download?os=windows) — you'll get a file named `SwarmConsole-Portable-<version>-x64.exe`.
2. Run it. Windows SmartScreen will likely show "Windows protected your PC" — click **More info**, then **Run anyway**. This app isn't code-signed yet, which is why SmartScreen flags it; it's expected.
3. Swarm Console will launch automatically once it finishes.
4. On first launch, paste the contents of the `.license` file from your welcome email into the activation screen.

## macOS

1. [Download the installer](https://swarm.intelligentit.io/download?os=mac) — you'll get a file named `SwarmConsole-<version>-mac-arm64.dmg`.
2. Open the `.dmg` and drag **Swarm Console** into your **Applications** folder.
3. Launch it from Applications. macOS Gatekeeper will likely block the first launch since the app isn't notarized yet — right-click the app icon, choose **Open**, then confirm **Open** in the dialog that appears. You only need to do this once.
4. On first launch, paste the contents of the `.license` file from your welcome email into the activation screen.

## Enabling LLM access (optional)

If your welcome email included a `.swarmkey` file, drop it into Swarm Console under **Setup > API Config** to enable LLM access.

## Trouble activating?

Reply to your license email or reach out to **ticket@intelligentit.io** and we'll get you sorted.
